# Paper 11 Decision Protocol Scope

**Doc class:** scope note  
**Status:** protocol scaffold only  

Paper 11 is a galaxy-scope decision protocol. It compares three model-family
roles under the same endpoint-blind freeze discipline:

1. `M0`: no-dark Tau morphology/readout endpoint.
2. `M1`: Tau base-substrate / Tau dark-sector response endpoint.
3. `M2`: standard dark-sector benchmark endpoint.

The paper does not decide global dark matter, dark energy, CMB, lensing, BAO,
growth, or cosmology. It asks a narrower question:

```text
For the declared galaxy-rotation endpoint class, does a dark-sector response
layer become necessary after source-frozen no-dark Tau morphology/readout is
tested against held-out data and controls?
```

The next target is a frozen policy-bundle instance.
